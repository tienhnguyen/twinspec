## Sentences

| Write | Not |
|---|---|
| `The option --library is missing` | `No --library, pass the path of a library folder.` |
| `The check made 2 findings` | `Checked 2 items.` |

- Write 1 idea in 1 sentence
- Put each sentence on its own line or list item or table cell
- End a sentence with the end of the line
- Put no period at the end of a sentence
- Use no commas
- Use no `and`
- Put a list of 2 or more things in a list or a table
- Split a long sentence into 2 sentences
- Keep a sentence at 15 words or fewer
- Use only 3 tenses
  - The simple present
  - The simple past
  - The simple future
- Use the active voice
- Start an instruction with a verb
- Write in the positive
- Never put 2 negatives in 1 sentence
- The rules of this section skip code in backticks
- Keep the exact words of a quote from another document

## Words

| Write | Not |
|---|---|
| return | give back |
| continue | go on |
| for example | `e.g.` |
| user | human |
| test as a verb | check as a verb |
| 1 | one |

- Write each text in English
- Use common words that a learner of English knows
- Use 1 word for 1 thing
- Repeat the noun when `it` or `this` can be unclear
- Use simple verbs
- Use no phrasal verbs
- Use no idioms
- Use no short forms like `don't` or `can't`
- Write numbers as digits
- Write each name of a file or a key or an id in backticks

## Order

- Show the main content first
- Put each code block or tree or table before the text about it
- Put the fact first
- Put the action on the next line
- Say what to do next
- Say the result directly so that the reader does not need to guess

## Errors

- Write an error in 1 sentence on 1 line
- Write 1 line for each problem when an error has many problems
- Say what is wrong so that the reader knows the next step
- Put the details in `--help` or the docs or the schemas

## Facts

- Write only what you tested or what an official page says
- Open each link before you add the link
